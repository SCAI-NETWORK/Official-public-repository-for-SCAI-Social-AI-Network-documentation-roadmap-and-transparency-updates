# Contributing

SCAI Social AI Network currently accepts public feedback through issues, documentation suggestions and responsible disclosure reports.

## Public Contributions

Accepted public contribution areas:

- Documentation corrections.
- Broken links.
- Public roadmap questions.
- Transparency-page suggestions.
- Security-report coordination through the responsible disclosure process.

Not accepted in public repositories:

- Private trading strategies.
- API keys, credentials or wallet secrets.
- Server details, infrastructure secrets or deployment material.
- Requests for financial, investment, legal, tax or trading advice.

## Security Issues

Do not open a public issue for a suspected vulnerability. Use the process in [SECURITY.md](SECURITY.md).

## Communication Standard

Keep feedback specific, respectful and reproducible. Public documentation exists to improve transparency while protecting the private execution layer of the SCAI platform.
