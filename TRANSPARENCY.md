# Transparency

SCAI Social AI Network is designed around public verification where appropriate and private protection where required.

## Public Transparency Layer

The project intends to maintain public references for:

- Token supply and deployment information.
- Presale batch structure.
- Allocation framework.
- Vesting and claim discipline.
- Smart-contract addresses and explorer links.
- Audit status and security-review material.
- Public roadmap and development updates.

## Private Protection Layer

The project does not publish:

- Proprietary trading logic.
- Bot execution code.
- API integrations and credential-handling internals.
- Server credentials, private keys, deployment secrets or signer material.
- Strategy-specific latency, scoring, filtering or routing internals.

This separation is intentional. Public investors should be able to verify the token, allocation and contract architecture without exposing the execution engine that gives the ecosystem operational value.

## Presale Batch Framework

Presale batches are designed to be transparent and contract-defined rather than handled through informal off-chain promises. Final public contract addresses and explorer links will be added after definitive deployment.

## Anti-Rug Principles

- Fixed-supply token model.
- Public allocation framework.
- Contract-defined vesting and claim logic.
- Wallet-bound investor dashboard.
- Public deployment references.
- External security-review path.

## Current Status

The public website and platform are under active development. Staging and testnet contract information may be published for transparency, but final production references should be treated as authoritative only after mainnet deployment and official announcement.
